# 🩸 Blood Donor Prediction

A Machine Learning project that predicts whether a person is likely to donate blood again based on their previous blood donation history.

The main goal of this project is to help identify potential blood donors using historical donation data and Machine Learning techniques.

## 📌 Project Overview

Blood banks often need to identify people who are more likely to donate blood again.
This project analyzes previous donation information and uses a classification model to predict whether a donor is likely to donate in the future.

## 🚀 Features

* Data preprocessing and cleaning
* Exploratory Data Analysis
* Machine Learning classification
* Blood donor prediction
* Model training and testing
* Prediction of donor status
* Simple and easy-to-understand implementation

## 🤖 Machine Learning Model

The project uses **Logistic Regression** for classification.

The model learns patterns from historical blood donation records and predicts whether a person is likely to donate blood again.

## 📊 Project Workflow

1. Import the dataset
2. Understand and analyze the data
3. Clean and preprocess the dataset
4. Select important features
5. Split the dataset into training and testing data
6. Train the Logistic Regression model
7. Make predictions
8. Evaluate the model
9. Use the trained model for blood donor prediction
